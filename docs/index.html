老人ホーム専科 動画パイプライン

本アプリケーションは、有限会社リアル・インテグリティが自己所有・自己運営する YouTubeチャンネル群に、自動生成した動画コンテンツをアップロードするための 社内業務用ツールです。一般公開されたサービスではなく、当社のみが利用します。

アプリの用途

台本生成・音声合成・画像/動画生成を行うローカルの動画自動生成パイプラインの 最終工程として、完成した動画ファイルをYouTube Data API v3 (youtube.uploadスコープ)経由で、当社が所有するYouTubeチャンネルに アップロードするために使用します。

アクセスするデータ

YouTube Data APIのyoutube.uploadスコープのみを使用し、 動画ファイルのアップロードとメタデータ(タイトル・概要・公開設定等)の登録のみを行います。 第三者のYouTubeアカウントやチャンネル情報へのアクセスは行いません。
